# Engineering record

How AegisContext was specified, built and measured, kept in the open. The guides for using it are one folder up ([docs](../README.md)).

| File | What it holds |
|---|---|
| [spec.md](spec.md) | The specification: goals, requirements (`R-` ids), the threat model, and the scope and known limits (section 22) |
| [plan.md](plan.md) | The build plan and the "Done when" check of each step |
| [decision-log.md](decision-log.md) | Every decision (`D-` ids), with why, what was rejected, and the evidence |
| [progress.md](progress.md) | Where the work stands, open items, and session notes |
| [findings-step0.md](findings-step0.md) | The facts about Claude Code checked on real machines before any code was written |
| [design-choices.md](design-choices.md) | The two most important design choices of each step, in plain language |
| [targets.md](targets.md) | The numbers a release has to meet, and how they were set |
| [release-checklist.md](release-checklist.md) | What has to be true before each release |
